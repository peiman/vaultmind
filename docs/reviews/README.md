# VaultMind reviews

Durable, dated reviews of this public open-core CLI. They are investigation
records, not product docs — findings can be wrong, stale, or already fixed.

Each review keeps its findings as written. What happened to them afterwards
goes in a "Resolution status" block at the top of the document, so the record
stays honest in both directions: the finding is not softened, and a reader is
not left re-fixing something that shipped.
